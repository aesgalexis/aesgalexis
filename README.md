# Alexis Santana

**Industrial technician and product builder working at the intersection of machines, software and AI.**

I've spent nearly two decades working with industrial machinery, troubleshooting, maintenance and operations, particularly in industrial laundry. I'm also the founder of [UNATOMO](https://unatomo.com), where I turn problems from the field into practical software and tools.

> I spent years fixing industrial machines. Now I also build the software around them.

## What I build

- Software that connects physical machines with their documentation, history and workflows.
- Small, useful tools for technicians and real-world operations.
- Desktop applications and experiments in AI-assisted automation.

## Selected projects

### Machines & field tools

- **[UNATOMO](https://unatomo.com)** — Machine-centered operational software: QR/NFC identification, documentation, history, tasks and equipment status. *Product website; source is private.*
- **[TechBench](https://github.com/aesgalexis/techbench)** · [Try it](https://aesgalexis.github.io/techbench/) — Practical mechanical, electrical and laundry-process calculators for technicians.
- **[PlateLens](https://github.com/aesgalexis/PlateLens)** · [Try it](https://aesgalexis.github.io/PlateLens/) — Extract structured, editable technical data from equipment nameplate photos in your browser.

### Desktop & automation

- **[HABITAT](https://github.com/aesgalexis/habitat)** — A native Windows desktop interface for working with ChatGPT through an existing Chrome session, alongside search and everyday tools.
- **[Codex Usage Meter](https://github.com/aesgalexis/codex-usage-meter-windows)** — A Windows tray app and desktop widget for monitoring Codex usage from local session data.
- **[model-switch](https://github.com/aesgalexis/model-switch)** — An experimental local reflex layer that reuses evidence and reduces unnecessary Codex tool work.

## Experiments

I'm also exploring local agents with [Agent Lab](https://github.com/aesgalexis/agent-lab) and controlled agent-to-social publishing with [Social Bridge](https://github.com/aesgalexis/social-bridge).

Most of these projects start the same way: there is a real problem, an annoying manual step, or a machine that knows less about itself than it should.
